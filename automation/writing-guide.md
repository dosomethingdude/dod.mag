## [철칙] 사실 기반 최신 정보 원칙

> **이 규칙은 모든 글 생성의 최우선 원칙입니다.**

### 1. 사실만 작성한다
- 확인되지 않은 정보, 추측, 루머는 **절대 작성 금지**
- 구체적인 수치(가격, 매출, 시장규모)는 **공식 발표 자료만** 인용
- 인용 가능한 공신력 있는 출처가 없으면 해당 정보는 **생략**
- "~로 알려졌다", "~라고 한다" 같은 불확실한 표현 대신 **출처 명시**
- 존재하지 않는 브랜드, 제품, 이벤트를 **만들어내지 않는다**
- 실제 기업/인물에 대한 **허위 정보 작성 금지**

### 2. 최신 정보를 반영한다
- **글 작성일 = 콘텐츠 기준일**: 오늘 날짜 기준으로 모든 정보 작성
- 제목/본문에 연도 언급 시 **반드시 현재 연도** 기준
- 과거 연도의 정보를 현재인 것처럼 작성 **금지**
- "올해", "최근" = **현재 연도**를 의미
- 통계/데이터: **현재 연도 또는 직전 연도** 자료만 사용
- 트렌드 키워드가 과거 이벤트라면 **현재 관점에서 재해석**

### 3. 출처를 반드시 포함한다
- 실제 존재하는 공식 기관, 언론사, 기업의 공식 발표만 사용
- "~리포트", "~조사" 등 **가상의 출처 금지**
- 출처 URL을 알고 있다면 **반드시 포함**
- 최소 **3개 이상**의 공신력 있는 출처 필수

**올바른 출처 예시:**
```
- 한국경제신문 (https://www.hankyung.com/...)
- McKinsey Global Institute (2026 Report)
- 트렌드코리아 2026
- Harvard Health Publishing
```

**잘못된 출처 예시:**
```
- 최근 연구에 따르면 (어떤 연구?)
- 전문가들은 말한다 (누구?)
- 업계 관계자에 의하면 (출처 불명)
```

## 브랜드 보이스

### 핵심 키워드
- **세련됨** (Sophisticated)
- **영감을 주는** (Inspiring)
- **트렌디하지만 깊이 있는** (Trendy yet Thoughtful)
- **친근하지만 전문적인** (Approachable yet Professional)

### 톤앤매너
- 독자를 **"당신"**으로 호칭 (친밀하지만 격식 있게)
- 명령형보다 **제안형** 사용 ("~해보세요" vs "~하세요")
- 과장된 표현 지양, **담백하고 세련된** 문체
- 영어 표현은 필요한 경우에만 자연스럽게 섞어 사용
- 단락 간 **자연스러운 흐름**과 논리적 연결

## 글 구조 템플릿

### 제목 (title / title_en)
- **25-35자** (한국어 기준)
- 숫자, 질문형, 또는 트렌드 키워드 포함
- 클릭을 유도하되 **낚시성 제목 지양**
- 영어 제목은 한국어의 **동등한 번역**

**좋은 예시:**
- "조용한 럭셔리, 2026년 우리가 주목해야 할 이유"
- "번아웃을 이기는 5가지 마이크로 습관"
- "파타고니아가 증명한 것: 진정성은 행동으로 완성된다"

**피해야 할 예시:**
- "충격! 이것만 알면 인생이 바뀝니다" (과장)
- "필독!!! 꼭 봐야 할 트렌드" (낚시성)

---

### 요약 (summary / summary_en)
- **100자 내외** (한국어 기준)
- 본문의 핵심 메시지를 함축
- 독자가 "왜 이 글을 읽어야 하는지" 명확히 전달
- 영어 요약은 한국어의 **동등한 번역**

---

### 한국어 본문 (content)

#### 분량: 5,000자 이상 (공백 포함)

```
■ 인트로 (400-500자)
- 트렌드 현상 또는 질문으로 시작
- 독자의 공감을 이끌어내는 도입부
- 이 주제가 왜 지금 중요한지 맥락 제시

■ 섹션 1: 배경과 맥락 (800-1000자)
- 주제의 역사적/사회적 배경
- 구체적인 데이터나 사례 인용
- "~에 따르면", "~의 조사에 의하면" 형식

■ 섹션 2: 핵심 분석 (1000-1200자)
- 왜 이것이 중요한지 깊이 있는 분석
- 전문가 의견 또는 브랜드 사례
- 다양한 관점에서의 시각 제공

■ 섹션 3: 트렌드와 변화 (800-1000자)
- 현재 트렌드와 향후 전망
- 관련 산업/분야의 움직임
- 글로벌 vs 로컬 시각 비교

■ 섹션 4: 실천 방안 (600-800자)
- 독자가 바로 적용할 수 있는 액션 아이템 3-5개
- 구체적이고 실현 가능한 제안
- 단계별 가이드 또는 추천 리스트

■ 클로징 (400-500자)
- 핵심 메시지 요약
- 미래 전망 또는 영감을 주는 마무리
- 여운을 남기는 마무리 문장

---
**참고자료**
- [출처명] (URL)
- 최소 3개 이상
```

#### 소제목 형식
- 각 섹션은 **`**굵은체 소제목**`**으로 구분
- 마크다운 `**텍스트**` 형식 사용 (HTML 아님)
- 소제목은 내용을 함축하는 짧고 인상적인 문구

---

### 영어 본문 (content_en)

> **요약(summary)이 절대 아닌, 한국어와 동등한 완전한 번역본**

- 한국어 본문과 **동등한 깊이, 구조, 분량** 유지
- **bold subheadings** 동일하게 사용
- 영어 독자에게 맞는 **자연스러운 표현**으로 번역 (직역 지양)
- 한국 고유 맥락(브랜드, 문화, 제도 등)은 **간략한 설명 추가**
- 참고자료 섹션도 동일하게 포함

**올바른 예:**
```
한국어: 2,000자 본문 → 영어: 동등한 분량의 완전한 기사
```

**잘못된 예:**
```
한국어: 5,000자 본문 → 영어: 500자 요약 (❌ 금지)
```

## 카테고리별 글쓰기 톤

### 인사이트 (Insights)
- **톤**: 분석적, 통찰력 있는
- **키워드**: 트렌드, 현상, 변화, 세대, 라이프스타일
- **참고 매체**: 트렌드코리아, McKinsey, Deloitte
- **글 방향**: 사회 현상 → 원인 분석 → 독자에게 주는 시사점

### 신상품 (Products)
- **톤**: 객관적이면서 영감을 주는
- **키워드**: 디자인, 기능, 라이프스타일, 혁신
- **참고 매체**: The Verge, CNET, 디자인 매거진
- **글 방향**: 제품/서비스 소개 → 특징 분석 → 실생활 활용법

### 라이프 (Life)
- **톤**: 따뜻하고 실용적인
- **키워드**: 웰빙, 루틴, 습관, 균형, 자기관리
- **참고 매체**: Harvard Health, Mayo Clinic
- **글 방향**: 건강/생활 주제 → 과학적 근거 → 실천 가능한 조언

### 브랜드 (Brands)
- **톤**: 스토리텔링, 영감을 주는
- **키워드**: 철학, 가치, 지속가능성, 장인정신
- **참고 매체**: Forbes, Business of Fashion
- **글 방향**: 브랜드 히스토리 → 핵심 가치/철학 → 독자에게 주는 영감

## 문체 규칙

### DO (권장)
- 짧은 문장과 긴 문장의 **리듬감 있는 배치**
- 구체적인 **숫자와 데이터** 활용
- 비유와 은유의 **절제된** 사용
- **소제목**으로 가독성 확보
- 독자에게 **실용적 정보** 제공
- **팩트에 기반한** 신뢰성 있는 정보 전달

### DON'T (지양)
- "정말", "진짜", "완전" 같은 구어체
- "~입니다", "~합니다"의 과도한 반복
- 이모지 사용
- 광고성 문구 ("최고의", "완벽한", "필수")
- 출처 없는 수치나 통계
- AI가 생성한 느낌이 드는 기계적 표현

## 이미지-콘텐츠 매칭 규칙

> 자동 생성 시 이미지는 `generate-posts.js`의 `KEYWORD_IMAGE_MAP`과 `IMAGE_POOL`에서 선택됩니다.

### 카테고리별 적합한 이미지 키워드

| 카테고리 | 적합한 이미지 | 부적합한 이미지 |
|----------|-------------|---------------|
| 인사이트 | 도시, 라이프스타일, 데이터, 사회 | 음식, 운동기구, 특정 제품 |
| 신상품 | 제품, 기술, 가젯, 자동차 | 자연 풍경, 추상화 |
| 라이프 | 웰빙, 건강, 요가, 자연 | 비즈니스, 기술 장비 |
| 브랜드 | 패션, 럭셔리, 매장, 디자인 | 의료, 스포츠 경기장 |

### 이미지 소스
- **Unsplash**: 저작권 무료 이미지만 사용
- **URL 형식**: `https://images.unsplash.com/photo-{ID}?w=1200&q=80`
- 모든 게시글에 **"이미지: Unsplash"** 출처 표기

## 글 하단 필수 문구

모든 글의 마지막에 자동으로 추가되는 문구:

```
---
* 이 포스팅은 AI어시스턴트와 협업하여 제작되었으며, 에디터의 편집을 통해 완성되었습니다.
```

영어:
```
---
* This article was created in collaboration with an AI assistant and finalized through editorial review.
```

## 출력 JSON 형식

```json
{
  "title": "제목 (25-35자)",
  "title_en": "English title (equivalent translation)",
  "summary": "요약 (100자 내외)",
  "summary_en": "English summary (equivalent translation)",
  "content": "한국어 본문 (5,000자 이상, 잡지 형식, **굵은체 소제목**, 참고자료 포함)",
  "content_en": "English full article (complete translation, NOT a summary)",
  "sources": ["출처1 (URL)", "출처2 (URL)", "출처3"]
}
```
